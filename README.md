# AI PM 經理人班 — 專案總索引

> 一套為「零技術背景的經理人 / 新手 PM」設計的 12 週 AI 產品經理養成課程。
> 全課程使用繁體中文，採「HTML 互動教材 + Markdown 自學指南」雙軌制。

最後更新：2026-10-16（v1.3 — W03 完成；驗證報告 **P0-3／P0-4 已處理**，P1-4 一併處理；名詞對照表更新至 v1.1）

---

## 一、專案定位

| 項目 | 內容 |
|---|---|
| 課程名稱 | AI PM 經理人班（AI Product Manager for Managers） |
| 目標對象 | 完全初學者、無程式或 AI 背景的經理人與新手 PM |
| 課程長度 | 12 週，每週 1 個主題（W06、W12 為重週，各給兩週完成窗口） |
| 學習階段 | 4 大階段：基礎認知 → AI 工具應用 → 軟性技能 → 整合應用 |
| 交付格式 | 每週一份 HTML 互動教材 + 一份 Markdown 自學指南 |
| 語言 | 繁體中文 |

**雙軌制的用途**

- **HTML 互動教材**：課堂或線上自學使用，含分頁導覽、自我檢驗互動、案例卡片，適合「第一次接觸」。
- **Markdown 自學指南**：深度閱讀與離線複習使用，內容更完整（每週 8,000 字以上），適合「課後消化與查閱」。

建議搭配使用：先看 HTML 建立整體圖像，再讀 Markdown 補齊細節，最後完成作業。

## 二、課程邊界與驗證（開發守則）

所有教材開發都必須遵守 `00-課程大綱/課程邊界與驗證規範.md`。三條邊界：

| 邊界 | 一句話 | 典型界外內容 |
|---|---|---|
| **A · 對象** | 給新手小白：零技術背景的在職工作者 | 程式碼、數學、開發環境 |
| **B · 工具** | 學習「使用」AI，不是「打造」AI | 模型訓練、API 串接、部署 |
| **C · 職能** | 學 PM 的判斷與溝通，不是完整 PM 學程 | 認證考照、法律意見、統計學 |

**每週教材的三個必備欄位**：本週新名詞（≤8 個）、給主管的提醒（每個核心概念各一則）、非 PM 背景替代作業（每份作業各一版）。

**名詞定義的統一出處**：`00-課程大綱/名詞對照表.md`。教材與該表不一致時以該表為準；每開發一週就把該週「本週新名詞」合併進去。

**內容驗證**：每週教材成稿後，須經五類專業人士測試驗證，其中必含「非產品經理背景的職場人」：

1. 現職產品經理 — 守**專業正確性**
2. 具備專案管理經驗人士 — 守**可執行性**
3. 部門主管與團隊領導者 — 守**決策價值**
4. 數位轉型推動者 — 守**落地路徑**
5. 非產品經理背景的職場人 ★ — 守**可理解性**（關鍵驗證者）

通過門檻、檢核表、回饋格式見規範文件；首次審查結果見 `00-課程大綱/驗證審查報告-v1.md`。

**工具與 Agent 內容的專屬守則**：W04–W07 的教材另須遵守 `00-課程大綱/AI工具與Agent教學規範.md`。該規範以 OpenAI 與 Anthropic 官方文件為事實基準，並把內容切成兩層：

| 層 | 內容 | 是否進學員教材 |
|---|---|---|
| **原則層** | 概念、判斷準則、提示寫法、Agent 派工框架、工具選擇決策樹 | ✅ 進主教材，廠牌中立表述 |
| **廠牌層** | 兩家的功能名稱、方案差異、用量上限、可否建立 | ⚠️ 僅進附錄 A（易過期，每 3 個月重查） |

核心規則：**原則層的每一條主張，必須兩家官方文件都說得通才寫進教材。**
